API Nore

Wydania, wydarzenia, gracze Nore i ping serwerów Minecraft. JSON bez klucza, z CORS i ETag. Wersja v2 działa pod /api/v2, a v1 zostaje dla starszych launcherów i modów.

Wszystkie adresy v2

Każda odpowiedź JSON to obiekt: sukces { "ok": true, … }, błąd { "ok": false, "status", "code", "error" } z opisem po polsku. Lista poniżej powstaje z opisu OpenAPI, więc zawsze zgadza się z serwerem.

  • GET /api/v2/status – stan API i komponentów
  • GET /api/v2/releases/latest – najnowsze wydanie
  • GET /api/v2/downloads – pliki i liczniki pobrań
  • GET /api/v2/events – wydarzenia z odliczaniem
  • GET /api/v2/players/{name} – Nore Hub: gracz
  • GET /api/v2/servers/{address} – ping serwera Minecraft
  • GET /api/v2/stats – statystyki

Zapytanie trafia na krawędź

Odpowiada serwer Cloudflare najbliżej Ciebie, nie jeden komputer gdzieś daleko.

Starsze API v1

Adresy /api/v1 działają bez zmian: wołają je wydane wersje Nore Launchera, Nore Updatera i moda. Nowe programy niech używają v2. Odpowiedzi v1 nie mają koperty ok.

Zanim zapytasz

Czy potrzebuję klucza?

Nie. Publiczne adresy działają bez rejestracji. Prosimy tylko, żeby jeden program nie pytał częściej niż co minutę: dane i tak zmieniają się co kilka minut. Ping serwerów ma limit 20 zapytań na minutę na IP.

Mogę wołać API z przeglądarki?

Tak. Publiczne odpowiedzi mają Access-Control-Allow-Origin: *, więc fetch() działa z każdej strony. Adresy panelu i bota nie są publiczne.

Co znaczy X-Nore-Cache?

HIT to świeże dane z pamięci, STALE to starsze dane podane od razu i odświeżane w tle, MISS to pierwsze zapytanie z danymi pobranymi na żywo.

Jak oszczędzać transfer?

Zapisz nagłówek ETag i wyślij go następnym razem w If-None-Match. Jeśli nic się nie zmieniło, dostaniesz pustą odpowiedź 304.

Jak rozpoznać błąd?

Po polu ok: false i kodzie HTTP. Pole code jest stałe (na przykład rate_limited), a error to opis dla ludzi. Błędy konfiguracji bota mają listę errors ze ścieżkami JSON Pointer.

Co wysyła Nore Hub?

Tylko gdy grasz: nick, UUID, Nore ID i ustawienia garderoby, co 60 s, i online: false po wyjściu z gry. Hello jest podpisane kluczem Nore ID (ECDSA P-256), a konto premium potwierdza Mojang. Wyłączysz to w launcherze: Ustawienia → „Pokazuj innym graczom Nore, że grasz w Nore”.

Czy v1 zniknie?

Nie. Adresy v1 zostają, bo wołają je wydane launchery. Nowe pola mogą dochodzić, ale żadne nie znika ani nie zmienia znaczenia.

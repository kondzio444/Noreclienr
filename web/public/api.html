Zanim zapytasz

Czy potrzebuję klucza?

Nie. Każdy endpoint jest publiczny i działa bez rejestracji. Prosimy tylko, żeby jeden program nie pytał częściej niż co minutę. Dane i tak zmieniają się co kilka minut.

Mogę wołać API z przeglądarki?

Tak. Odpowiedzi mają Access-Control-Allow-Origin: *, więc fetch() działa z każdej strony, także z Twojej.

Jak świeże są dane?

Co 15 minut Cron Trigger pobiera wydania z GitHuba w tle. Między synchronizacjami odpowiedź przychodzi z pamięci, a starsza niż 5 minut odświeża się w tle przy pierwszym zapytaniu.

Co znaczy X-Nore-Cache?

HIT to świeże dane z pamięci. STALE to starsze dane podane od razu, które w tle właśnie się odświeżają. MISS to pierwsze zapytanie, z danymi pobranymi na żywo.

Jak oszczędzać transfer?

Zapisz nagłówek ETag i wyślij go następnym razem w If-None-Match. Jeśli nic się nie zmieniło, dostaniesz pustą odpowiedź 304.

Skąd są pliki do pobrania?

Z GitHub Releases repozytorium kondzio444/Noreclienr. API podaje adres, rozmiar i SHA-256, a /download przekierowuje prosto do pliku.

Czy API się zmieni?

Adresy /api/v1 zostają. Nowe pola mogą dochodzić, ale żadne nie znika ani nie zmienia znaczenia. Zmiana, która coś psuje, dostałaby nowe /api/v2.

Co wysyła Nore Hub?

Tylko gdy grasz: nick, UUID, Nore ID i ustawienia garderoby, co 60 s i online: false po wyjściu z gry. Hello jest podpisane kluczem Nore ID (ECDSA P-256), a konto premium potwierdza Mojang (hasJoined). Nick bez premium należy do pierwszego Nore ID, które go zgłosi, przez 30 dni od ostatniej gry. Wyłączysz to w launcherze: Ustawienia → „Pokazuj innym graczom Nore, że grasz w Nore”.

Czy jest Forge?

Parametr loader w /updates/mod przyjmuje fabric albo forge. Lista z /platforms mówi, co jest dostępne dla danej wersji.

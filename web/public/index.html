    FAQ

    Czy potrzebuję konta premium?

    Nie. Możesz zalogować się kontem Microsoft (Minecraft: Java Edition albo Game Pass) albo grać na samym nicku – w singleplayerze, LAN i na serwerach non-premium.

    Czy kosmetyki widzą inni gracze?

    Nie. Peleryny, skrzydła, kapelusz i własne niebo widzisz tylko Ty.

    Jak działa aktualizacja?

    Launcher pyta API Nore o nową wersję i pobiera ją w tle. Modpacki i mody aktualizują się bez utraty światów.

    Czy da się wyłączyć wydarzenia?

    Nie. Halloween jest włączony teraz, a zimowy event włączy się sam 10 grudnia 2026.

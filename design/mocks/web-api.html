API Nore

Wydania, wydarzenia, gracze Nore i ping serwerów Minecraft. JSON bez klucza, z CORS i ETag. Wersja v2 pod /api/v2, a v1 działa dalej dla starszych launcherów.

Działa · dane sprzed 4 minOpenAPI 3.1Bez klucza
GET/api/v2/servers/{adres}

Pinguje serwer Minecraft i zwraca, czy działa, ilu graczy jest teraz, wersję, MOTD i ikonę. Tego samego używa Nore Bot w komendzie /serwer.

editionjava (domyślnie) albo bedrock.
